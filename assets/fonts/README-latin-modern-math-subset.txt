latin-modern-math-subset.woff2
==============================

This file is a derived version of Latin Modern Math, version 1.959 (5 September 2014),
by Bogusław Jackowski, Piotr Strzelczyk and Piotr Pianowski, on behalf of the TeX users
groups (GUST e-foundry). It is used to set the formulas on attention.html and kuhn.html.

Changes made to the original latinmodern-math.otf (November 2026):
  - kept only the characters the formulas need (Basic Latin, Latin-1, Greek, prime,
    arrows, mathematical operators, mathematical italic letters), together with the
    MATH table and its glyph variants;
  - converted to WOFF2;
  - renamed the font to "Latin Modern Math Subset" so that it cannot be mistaken
    for the original.

The original is distributed under the GUST Font License (GUST-FONT-LICENSE.txt in this
folder), an instance of the LaTeX Project Public License 1.3c. The authors of the
original provide no support for this subset.

A complete, unmodified copy of Latin Modern Math is available from GUST e-foundry,
https://www.gust.org.pl/projects/e-foundry/lm-math, and from CTAN,
https://ctan.org/pkg/lm-math.
